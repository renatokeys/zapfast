FAQ

Perguntas frequentes

O zapfast é mesmo gratuito?
Sim. Self-hosted é 100% grátis sob licença MIT. Você paga apenas a infra onde roda (VPS, GCP, AWS).
Posso migrar minha integração Z-API sem mudar código?
Sim. Os endpoints REST replicam o contrato da Z-API. Só troque a base URL e o token e pronto.
Funciona com WhatsApp Business?
Funciona com qualquer número conectado via QR code (WhatsApp pessoal ou Business). Para WhatsApp Cloud API oficial use nosso adapter dedicado (em breve).
Quanta CPU/RAM preciso?
Numa VPS de 4 vCPU e 8GB RAM você roda confortavelmente 1000+ instâncias simultâneas. Pra 10 instâncias um Raspberry Pi 4 já basta.
Tem risco de banimento no WhatsApp?
O zapfast usa whatsmeow, a mesma biblioteca de WhatsApp Web. Disparos massivos sem opt-in podem causar banimento — siga sempre as políticas oficiais da Meta.
Posso contribuir com o projeto?
Por favor! Abra issues, PRs e suba forks à vontade. Licença MIT.
